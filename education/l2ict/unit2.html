UNIT TWO TECHNOLOGY SYSTEMS

Introduction

This unit covers the integral core systems that make up the tech we use in our daily lives, learning the details and function of the hardware inside our devices, such as laptops, desktops, phones, etc. It also covers how software plays it’s part in making our systems work, ranging from the operating system which provides a base for our user application software, while handling the low-level hardware communication essential to interact with the system ourselves. Which we also learn more about the types and roles of applications software we run on the OS, ranging from the Office suite to Computer Aided Design tools.
